## Planned real recording flow

The future recording should follow a real local application path:

1. Scope a ticket in the integrated tracker.
2. Inspect the scoped ticket and its execution configuration.
3. Open **Execute**, confirm the selected workflow and role/model routing, and
   start the run.
4. Follow the actual graph stages as they progress through the application.
5. Open the resulting pull request from the completed delivery surface.

The recording will be documented only after that flow has been performed and
reviewed. This plan does not claim a completed run, provider execution, pull
request, or hosted availability.
